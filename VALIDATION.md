## Замер памяти

Замер выполнен на Windows. Тестовый файл создан до начала
измерения. В нём повторяется одна JSONL-запись с источником benchmark
и сообщением длиной 1024 символа.

| Размер файла | Событий | Пик по tracemalloc | Время анализа |
|---:|---:|---:|---:|
| 16 777 340 байт (16 МиБ) | 15 020 | 158 218 байт (154,51 КиБ) | 0,20 с |
| 536 871 529 байт (512 МиБ) | 480 637 | 163 400 байт (159,57 КиБ) | 6,48 с |

tracemalloc измеряет выделения памяти Python во время анализа. При росте
числа уникальных источников увеличивается размер счётчиков.

Для повторения замера выполнить команды в папке проекта после установки
пакета. Имена тестовых файлов должны быть свободны.

```powershell
New-Item -ItemType Directory -Force .tmp
.\.venv\Scripts\python.exe -m scripts.measure_memory .tmp\benchmark-16.jsonl 16
.\.venv\Scripts\python.exe -m scripts.measure_memory .tmp\benchmark-512.jsonl 512
```
